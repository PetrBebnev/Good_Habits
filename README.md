# 🌱 Полезные привычки — трекер

Веб-приложение на **Flask** для отслеживания полезных привычек: помогает
формировать полезные ритуалы, следить за прогрессом и видеть статистику
по категориям.

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![Flask](https://img.shields.io/badge/Flask-3.0-green)
![License](https://img.shields.io/badge/license-MIT-lightgrey)

---

## 📖 Описание

**Полезные привычки** — это простой трекер, в котором пользователь:

- знакомится с приложением на главной странице;
- переходит к списку из **12 привычек** (вода, зарядка, чтение, медитация и др.);
- отмечает выполненные привычки одним нажатием;
- видит прогресс в процентах и разбивку по категориям;
- может сбросить прогресс и начать заново.

Прогресс сохраняется между запросами благодаря **сессии Flask**.

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/ВАШ-ЛОГИН/habits-tracker.git
cd habits-tracker
```

### 2. Создание виртуального окружения

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу: **http://127.0.0.1:5000**

## 🧠 Как это работает

1. **Данные** о привычках лежат в `data.py` — список словарей с полями
   `id`, `title`, `description`, `category`, `image`.
2. При отметке привычки её `id` добавляется в `session["completed"]`.
3. На странице `/progress` вычисляется:
   - количество выполненных привычек;
   - процент выполнения;
   - статистика по каждой категории;
   - мотивационное сообщение.
4. Прогресс **сохраняется** между запросами благодаря Flask session,
   пока пользователь не закроет браузер или не сбросит данные.

## 🛡 Защита от ошибок

- ❌ Пустой `habit_id` в форме → сообщение об ошибке
- ❌ Несуществующий `id` привычки → понятное предупреждение
- ❌ Повторная отметка привычки → предупреждение «уже выполнена»
- ❌ Случайный URL → страница **404** с описанием
- ❌ Внутренняя ошибка сервера → страница **500**
- ❌ Сброс прогресса → подтверждение через `confirm()`
